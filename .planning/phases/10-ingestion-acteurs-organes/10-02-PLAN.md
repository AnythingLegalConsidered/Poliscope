  <name>Task 1: AN organs ingestion pipeline</name>
  <files>packages/ingestion/scripts/ingest_organs_an.py</files>
  <action>
Create `ingest_organs_an.py` that extracts AN organs from the same AMO10 ZIP used by ingest_actors_an.py:

1. **Download**: Use `download_zip_json_files(AN_OPENDATA_ZIP)`. Filter for files matching `json/organe/PO*.json`.

   **Optimization**: If ingest_actors_an.py already downloaded the ZIP in the same pipeline run, consider caching. BUT since scripts run as subprocesses, each is independent — just re-download. The ZIP is small (~5MB) and this is a batch job.

2. **Map function `map_an_organ(raw: dict) -> dict`**:

   Use `ORGAN_TYPE_MAP` to convert AN codeType to our schema:
   ```python
   ORGAN_TYPE_MAP = {
       "GP": "group",
       "COMPER": "commission",
       "DELEG": "delegation",
       "OFFPAR": "other",
       "BUREAU": "other",
       "ASSEMBLEE": "other",
       "CMP": "other",
       "COMNL": "commission",
       "CNPS": "other",
       "CNPE": "other",
       "GA": "other",
       "GE": "other",
       "GROUPEAMITIE": "other",
   }
   ```

   Map fields:
   - `official_id`: `raw["uid"]` (e.g., "PO59046")
   - `name`: `raw.get("libelle", "")`
   - `short_name`: `raw.get("libelleAbrege") or raw.get("libelleAbrev")`
   - `organ_type`: `ORGAN_TYPE_MAP.get(raw.get("codeType", ""), "other")`
   - `chamber`: `"AN"`
   - `legislature_id`: `None` — set nullable for now (legislature seeded by 10-01 but we'd need a lookup to get the ID; keep simple)
   - `parent_organ_id`: `None` — no FK constraint, skip resolution
   - `start_date`: `raw.get("viMoDe", {}).get("dateDebut")`
   - `end_date`: `raw.get("viMoDe", {}).get("dateFin")`

   **Filter**: Only ingest organs with codeType in `["GP", "COMPER", "DELEG"]` — skip ASSEMBLEE, BUREAU, OFFPAR (these are meta-organs, not useful for actor-organ queries). This keeps the organs table focused. If the codeType is not in the filter list, skip the organ.

3. **Upsert**: `upsert_query(table="organs", columns=ORGAN_COLUMNS, conflict_column="official_id", has_updated_at=False)`. The organs table has no updated_at column — check schema. If it has created_at only, set `has_updated_at=False`.

   `ORGAN_COLUMNS` = `["official_id", "name", "short_name", "organ_type", "chamber", "legislature_id", "parent_organ_id", "start_date", "end_date"]`

4. **Also resolve political_group on actors**: After organs are ingested, UPDATE actors SET political_group = organs.short_name (or organs.name) WHERE actors.political_group matches a PO ID. This is needed because ingest_actors_an.py stores the PO reference (e.g., "PO845514") in political_group, not the human-readable name.

   ```sql
   UPDATE actors SET political_group = o.short_name
   FROM organs o WHERE actors.political_group = o.official_id
   AND actors.chamber = 'AN' AND o.organ_type = 'group';
   ```

   Log how many actors were updated.

5. **Main block**: Standard pattern — logging, try/except, count log.

   ```python
       "COMMISSION": "commission",
       "ETUDE": "other",
       "GIA": "other",
       "DELEGATION": "delegation",
       "OFFICE": "other",
   }
   ```

   Also extract political groups from the `groupe` field of each senator — these are separate organs not in organismes[].

3. **Map function `map_senat_organ(code, type_str, libelle) -> dict`**:
   - `official_id`: `f"SENAT_{code}"` — prefix to avoid collision with AN PO IDs
   - `name`: `libelle`
   - `short_name`: `code` (short identifier)
   - `organ_type`: `SENAT_ORGAN_TYPE_MAP.get(type_str, "other")`
   - `chamber`: `"Senat"`
   - `legislature_id`: `None`
   - `parent_organ_id`: `None`
   - `start_date`: `None` (not available in API)
   - `end_date`: `None`

   For political groups from `groupe.libelle`:
   - `official_id`: `f"SENAT_GP_{slugified_libelle}"` — create a stable ID from group name
   - `organ_type`: `"group"`
   - `short_name`: `raw.get("groupe", {}).get("libelle")` (the short label like "RDPI")

4. **Filter**: Only ingest organs with type in `["COMMISSION", "DELEGATION"]` + all political groups. Skip ETUDE, GIA, OFFICE (not in Phase 10 scope per research).

   - `id` INTEGER PK GENERATED ALWAYS AS IDENTITY
   - `actorId` INTEGER NOT NULL FK actors.id ON DELETE CASCADE
   - `organId` INTEGER NOT NULL FK organs.id ON DELETE CASCADE
   - `role` TEXT — nullable, e.g. "membre", "president", "vice-president"
   - `startDate` TIMESTAMP — mandat start (dateDebut from AMO10)
   - `endDate` TIMESTAMP — mandat end (dateFin from AMO10, nullable = still active)
   - `createdAt` TIMESTAMP DEFAULT NOW NOT NULL
   - Add composite unique constraint on (actor_id, organ_id) to enable idempotent upsert
   - Add indexes: idx_actor_organs_actor on actorId, idx_actor_organs_organ on organId

2. Create hand-written migration `packages/shared/drizzle/0004_actor-organs.sql`:
   ```sql
   CREATE TABLE IF NOT EXISTS actor_organs (
     id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
     actor_id INTEGER NOT NULL REFERENCES actors(id) ON DELETE CASCADE,
     organ_id INTEGER NOT NULL REFERENCES organs(id) ON DELETE CASCADE,
     role TEXT,
     start_date TIMESTAMP,
     end_date TIMESTAMP,
     created_at TIMESTAMP DEFAULT NOW() NOT NULL,
     CONSTRAINT actor_organs_actor_organ_unique UNIQUE (actor_id, organ_id)
   );
   CREATE INDEX IF NOT EXISTS idx_actor_organs_actor ON actor_organs(actor_id);
   CREATE INDEX IF NOT EXISTS idx_actor_organs_organ ON actor_organs(organ_id);
   GRANT ALL ON TABLE actor_organs TO poliscope;
   GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO poliscope;
   ```

3. Update `packages/shared/drizzle/meta/_journal.json`: add entry idx=4, tag="0004_actor-organs", with a timestamp.

4. Apply migration to live DB via SSH: `ssh poliscope-db "psql -U poliscope -d poliscope -f -" < packages/shared/drizzle/0004_actor-organs.sql`

NOTE: Use the same hand-written migration pattern as 0003. Do NOT use drizzle-kit generate (per Phase 9 decision — --custom mode with manual snapshot).

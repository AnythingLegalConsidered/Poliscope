  <files>app/pages/index.vue</files>
  <action>
    Rewrite `app/pages/index.vue` to show a paginated, infinitely-scrolling list of debates.

    Implementation:
    1. Keep a heading "Debats de l'Assemblee nationale" at top (h1, text-2xl font-bold text-primary)
    2. Use `useFetch('/api/debates', { query: { page, limit: 20 }, lazy: true, watch: [page] })` with a reactive `page = ref(1)`
    3. Maintain `allDebates = ref<any[]>([])` — append new results when `data` changes via `watch(data, ...)`
    4. Compute `hasMore` from pagination: `page.value < data.value.pagination.totalPages`
    5. Use `useIntersectionObserver` from `@vueuse/core` on a sentinel `<div ref="sentinel">` at the bottom of the list:
       - Import: `import { useIntersectionObserver } from '@vueuse/core'`
       - Callback: if isIntersecting AND status !== 'pending' AND hasMore → increment page
       - Options: `{ rootMargin: '200px' }` to pre-load before sentinel is visible
    6. Use `useTemplateRef('sentinel')` for the sentinel ref (Nuxt 4 / Vue 3.5+ pattern)
    7. Render debates in a grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`
    8. Each debate → `<DebateCard v-for="debate in allDebates" :key="debate.id" v-bind="debate" />`
    9. Show `<LoadingSpinner />` when status === 'pending'
    10. Show "Aucun debat trouve" if allDebates is empty and status !== 'pending'
    11. Show "Tous les debats charges" text when !hasMore and allDebates.length > 0

    Guard against double-trigger: check `status.value !== 'pending'` before incrementing page in the observer callback.

    IMPORTANT: The `watch` on `data` must use `{ immediate: true }` to catch the initial SSR-hydrated data.
    IMPORTANT: The `useFetch` `watch` option re-fetches when `page` changes. Do NOT call `refresh()` manually.

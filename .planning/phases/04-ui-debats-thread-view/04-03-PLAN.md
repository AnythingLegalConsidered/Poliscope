  <action>
    Create `app/pages/debates/[id].vue` — the debate thread view.

    Implementation:
    1. **Route validation** — use `definePageMeta` with `validate` to ensure `route.params.id` is a positive integer (regex: `/^\d+$/`)

    2. **Data fetching** — use `useFetch` to load the debate:
       ```
       const route = useRoute()
       const { data, status, error } = await useFetch(`/api/debates/${route.params.id}`)
       ```
       This returns `{ debate: {...}, interventions: [...] }` — all interventions in one call (no pagination needed for now).

    3. **SEO** — use `useHead` to set page title: `data.value?.debate.title + ' — Poliscope'`

    4. **Page header section:**
       - Back link: `<NuxtLink to="/" class="text-primary hover:underline text-sm">` with arrow "← Retour aux debats"
       - Debate title: h1, text-xl font-bold text-gray-900
       - Metadata line: formatted date (Intl.DateTimeFormat 'fr-FR', dateStyle: 'long', timeZone: 'Europe/Paris') + session type if present
       - Intervention count: "N interventions" in text-sm text-gray-500
       - Bottom border to separate from thread

    5. **Thread body:**
       - Render interventions with `<InterventionCard v-for="intervention in data.interventions" :key="intervention.id" v-bind="intervention" />`
       - The v-bind spreads all props that InterventionCard expects (speakerName, speakerRole, content, orderInDebate, deputy, tags)
       - Wrap in a `max-w-2xl mx-auto` container for readable line width (like Twitter)

    6. **States:**
       - Loading: show `<LoadingSpinner />` when `status === 'pending'`
       - Error: show error message with "Debat introuvable" for 404, generic message otherwise
       - Empty: if debate has 0 interventions (unlikely but handle it), show "Aucune intervention"

    7. **Performance note:** Some debates have 1000+ interventions. The browser can handle rendering ~1000 simple DOM nodes. Do NOT add virtual scrolling — it's premature optimization. If it becomes an issue, it'll be addressed in a future phase.

    IMPORTANT: Use optional chaining on `data.value` in template (`data?.debate`, `data?.interventions`) since data can be null during loading.
    IMPORTANT: Format dates with explicit locale to prevent SSR hydration mismatch.
  </action>

    1. Creer `scripts/tags_dictionary.py`:
       - Exporter `TAGS_DICTIONARY`: dict[str, list[str]] avec 12 categories thematiques.
       - Categories et mots-cles (reprendre de la research):
         - "economie": budget, impot, fiscal, dette, economie, finance, emploi, chomage, entreprise, croissance, inflation
         - "securite": securite, police, gendarmerie, terrorisme, defense, armee, militaire, delinquance, criminalite
         - "sante": sante, hopital, medecin, medicament, epidemie, vaccination, soignant, maladie, assurance maladie
         - "education": education, ecole, enseignant, universite, etudiant, formation, pedagogie, baccalaureat
         - "environnement": environnement, ecologie, climat, energie, renouvelable, pollution, biodiversite, carbone
         - "justice": justice, tribunal, magistrat, penal, prison, juridique, loi, droit
         - "immigration": immigration, migrant, asile, frontiere, naturalisation, etranger
         - "logement": logement, immobilier, loyer, hlm, hebergement, urbanisme, construction
         - "transport": transport, sncf, route, autoroute, ferroviaire, aerien, mobilite
         - "agriculture": agriculture, agricole, paysan, elevage, pac, alimentation, pesticide
         - "numerique": numerique, internet, donnees, cybersecurite, intelligence artificielle, telecoms, fibre
         - "culture": culture, patrimoine, musee, spectacle, audiovisuel, artiste, cinema
       - Exporter aussi `TAGS_DISPLAY_NAMES`: dict[str, str] qui mappe slug -> nom affichable ("economie" -> "Economie", "securite" -> "Securite", etc.)
       - Fonction `tag_content(content: str) -> list[str]` qui retourne les slugs des tags matchant le contenu (recherche case-insensitive dans le texte).

    2. Creer `scripts/tag_interventions.py`:
       - **Etape 1**: Inserer/upsert les tags dans la table `tags`. Pour chaque categorie du dictionnaire, INSERT INTO tags (name, slug) VALUES (...) ON CONFLICT (slug) DO NOTHING. Le `name` est le display name, le `slug` est la cle du dictionnaire.
       - **Etape 2**: Charger le mapping `{slug: tag_id}` depuis la DB.
       - **Etape 3**: Fetch les interventions a tagger. Query: `SELECT id, content FROM interventions WHERE id NOT IN (SELECT DISTINCT intervention_id FROM intervention_tags)` pour ne traiter que les interventions pas encore taguees (incrementalite).
       - **Etape 4**: Pour chaque intervention, appeler `tag_content(content)`. Pour chaque slug retourne, INSERT INTO intervention_tags (intervention_id, tag_id) VALUES (...) ON CONFLICT DO NOTHING.
       - Committer par batch de 100 interventions pour la performance.
       - Afficher progression avec tqdm.
       - Log final: X interventions traitees, Y tags assignes, Z interventions sans tag.

       **Option --retag-all**: Si passe, ignorer le filtre NOT IN et re-tagger toutes les interventions (utile si on modifie le dictionnaire). Supprimer d'abord les anciens tags: DELETE FROM intervention_tags.

       **Note performance**: Pour un grand nombre d'interventions, utiliser `executemany` ou `copy` de psycopg pour les batch inserts plutot que des INSERT individuels.
  </action>

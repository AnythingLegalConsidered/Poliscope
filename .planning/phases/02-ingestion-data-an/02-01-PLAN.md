<task type="auto">
  <name>Task 2: Script d'ingestion des deputes</name>
  <files>
    scripts/ingest_deputies.py
  </files>
  <action>
    Creer `scripts/ingest_deputies.py` qui:

    1. **Fetch**: GET `{NOSDEPUTES_BASE}/deputes/json` via `fetch_json()`. Le JSON retourne `{"deputes": [{"depute": {...}}, ...]}`. Extraire la liste interne.

    2. **Map**: Pour chaque depute brut, mapper vers le schema DB:
       - `official_id`: `str(raw["id_an"])` si present, sinon `str(raw["id"])`. C'est la cle de jointure avec l'AN.
       - `first_name`: `raw["prenom"]`
       - `last_name`: `raw["nom_de_famille"]`
       - `full_name`: `raw["nom"]`
       - `political_group`: `raw["groupe_sigle"]` (peut etre None)
       - `photo_url`: `f"{NOSDEPUTES_BASE}/depute/photo/{raw['slug']}/120"` si slug present
       - `constituency`: `f"{raw['nom_circo']} ({raw['num_circo']})"` si les champs existent
       - `is_active`: `True` si `mandat_fin` est None ou vide

    3. **Upsert**: INSERT INTO deputies ... ON CONFLICT (official_id) DO UPDATE SET political_group, photo_url, constituency, is_active, updated_at = NOW(). Ne JAMAIS inclure `id` dans l'INSERT (colonne GENERATED ALWAYS AS IDENTITY).

    4. **Commit et log**: Compter le nombre de deputes inseres/mis a jour. Log final avec tqdm ou print.

    5. **Main guard**: `if __name__ == "__main__":` execute le pipeline complet. Gerer les erreurs avec try/except au top level et logging.

    Note: L'API nosdeputes.fr peut retourner des deputes avec `mandat_fin` non-null (anciens deputes de la legislature). On les importe quand meme avec `is_active = False` car ils peuvent avoir des interventions.
  </action>

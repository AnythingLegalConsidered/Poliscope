**DeputyCard.vue** — Create card component mirroring DebateCard.vue design pattern:
- Props: `id: number`, `fullName: string`, `group: string | null`, `photoUrl: string | null`, `constituency: string | null`

- Template: `NuxtLink` wrapper to `/deputies/${id}`, `bg-parchment rounded-xl border border-stone-border p-4 hover:border-bronze/40 transition-colors duration-200`

**deputies/index.vue** — Deputies list page following index.vue (debates list) pattern exactly:
- Page title: "Députés de l'Assemblée nationale" (h1, font-heading)
- Search input: `v-model="search"`, debounced with `watchDebounced` from @vueuse/core (300ms) or manual `watch` with `nextTick`. Use a `debouncedSearch` ref that the query watches, so typing doesn't spam API.
  - Actually, simpler approach per research: `search` ref bound to input, `watch([search, group])` resets `allDeputies = []` and `page = 1`. useFetch `query: { page, search, group }` with `watch: [page, search, group]` handles the rest. The API already handles empty search gracefully.
- Group filter: `select` dropdown with all political groups. Populate from a hardcoded list of known groups OR extract unique groups from loaded data. Simplest: hardcoded `['RN', 'EPR', 'LFI-NFP', 'SOC', 'DR', 'HOR', 'EcoS', 'LIOT', 'GDR', 'NI', 'UDR']` with labels via `getGroupLabel()`. Include "Tous les groupes" option (value null).
- Grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4` (same as debates)
- Infinite scroll: `useIntersectionObserver` from @vueuse/core on sentinel element (same pattern as index.vue)
- Loading: `LoadingSpinner` when `status === 'pending'`
- Empty state: "Aucun député trouvé" when no results
- "Tous les députés chargés" message when `!hasMore && allDeputies.length > 0`

**Critical patterns to follow:**
- `allDeputies` accumulator ref, `watch(data)` appends/replaces based on `page.value === 1`
- Filter change watcher: `watch([search, group], () => { allDeputies.value = []; page.value = 1 })`
- useFetch: `await useFetch('/api/deputies', { query: { page, limit: 20, search, group }, lazy: true, watch: [page, search, group] })`
- hasMore computed: `page.value < data.value.pagination.totalPages`

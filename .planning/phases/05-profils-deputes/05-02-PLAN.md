<task type="auto">
  <name>Task 1: Deputy profile page with stats, tag filter, and paginated interventions</name>
  <files>app/pages/deputies/[id].vue</files>
  <action>
Create `app/pages/deputies/[id].vue` following the debates/[id].vue pattern:

**Page setup:**
- `definePageMeta({ validate: (route) => /^\d+$/.test(String(route.params.id)) })`
- `useHead({ title: computed(() => (data.value?.deputy?.fullName ?? 'Député') + ' — Poliscope') })`

**Data fetching:**
- `const page = ref(1)`
- `const { data, status, error } = await useFetch(\`/api/deputies/${route.params.id}\`, { query: { page }, watch: [page] })`
- API returns `{ deputy, interventions: { data, pagination }, tagStats }`

**Tag filtering (client-side):**
- `const activeTag = ref<string | null>(null)`
- `const filteredInterventions = computed(() => { if (!activeTag.value) return data.value?.interventions?.data ?? []; return (data.value?.interventions?.data ?? []).filter(i => i.tags.some(t => t.slug === activeTag.value)) })`
- Reset `activeTag` to null when `page` changes: `watch(page, () => { activeTag.value = null })`

**Template structure (top to bottom):**

1. **Back link:** `NuxtLink to="/deputies"` — "← Retour aux députés" (text-bronze, same style as debates/[id].vue back link)

2. **Deputy header section** (border-b border-stone-border pb-4 mb-4):
   - Flex row: large photo (w-20 h-20 rounded-full, or initials fallback with bg-bronze) on left
   - Right side: fullName (h1, text-xl font-bold font-heading), GroupBadge, constituency (text-sm text-ink-muted)
   - Add `@error` handler on img for broken photo fallback
   - Below: intervention count from `data.interventions.pagination.total` — "{N} interventions"

3. **Tag stats section** (mb-6):
   - Row of clickable tag pills: `button` elements for each tag in `data.tagStats` (limit to top 8 or show all if <= 10)
   - Each pill: `px-2 py-0.5 rounded-full text-xs bg-marble-dark border border-stone-border hover:border-bronze/40 transition-colors`
   - Active state: `border-bronze text-bronze` when `activeTag === tag.slug`
   - Click toggles: `@click="activeTag = activeTag === tag.slug ? null : tag.slug"`
   - Show tag count in muted text: `{{ tag.name }} <span class="text-ink-muted">{{ tag.count }}</span>`

4. **Interventions list:**
   - Iterate over `filteredInterventions` (not `data.interventions.data` directly)
   - For each intervention, show a debate context line ABOVE the InterventionCard:
     ```html
     <div class="text-xs text-ink-muted mt-4 mb-1">
       <NuxtLink :to="`/debates/${intervention.debateId}`" class="text-bronze hover:text-bronze-dark transition-colors duration-200">
         {{ intervention.debate?.title ?? 'Débat' }}
       </NuxtLink>
       <span v-if="intervention.debate?.date"> · {{ formatDate(intervention.debate.date) }}</span>
     </div>
     <InterventionCard v-bind="intervention" />
     ```
   - `formatDate` helper: same `Intl.DateTimeFormat('fr-FR', { dateStyle: 'long', timeZone: 'Europe/Paris' })` pattern

5. **Pagination controls:**
   - "Charger plus" button when `page < data.interventions.pagination.totalPages`, styled: `bg-parchment border border-stone-border rounded-xl px-4 py-2 text-sm text-ink hover:border-bronze/40 transition-colors`
   - OR use infinite scroll with sentinel (same pattern as debates list). Either is acceptable — use "load more" button for simpler UX on profile page.
   - Show "Toutes les interventions chargées" when no more pages

6. **Loading/error states:** Same pattern as debates/[id].vue — LoadingSpinner, error messages for 404 and generic errors.

**Note on interventions accumulation:** Since useFetch with `watch: [page]` replaces data on each page change (not appends), each page view shows that page's interventions. This is simpler than infinite scroll accumulation. If you want accumulation, follow the index.vue pattern with `allInterventions` ref. Choose the simpler approach: just show current page with prev/next or "load more" that increments page. Accept that tag filter applies to current page only.

Simpler approach for MVP: Do NOT accumulate. Just show the current page of interventions. Pagination: "Page X sur Y" with prev/next buttons OR a simple "Charger plus" that accumulates like index.vue. Go with accumulation + "load more" button for consistency with the rest of the app.

Final approach (consistent with app patterns): Use `allInterventions` accumulator ref + watch(data) appender (same as index.vue `allDebates` pattern). "Load more" button increments page. Tag filter operates on `allInterventions` (all loaded so far). This gives best UX.

  <name>Task 2: Add deputyId prop to InterventionCard for bidirectional navigation</name>
  <files>app/components/InterventionCard.vue</files>
  <action>
Modify `app/components/InterventionCard.vue` to support deputy profile links:

1. **Add `deputyId` to props interface:**
```typescript
const props = defineProps<{
  speakerName: string
  speakerRole: string | null
  content: string
  orderInDebate: number
  deputy: Deputy | null
  tags: Tag[]
  deputyId?: number | null  // NEW — enables link to deputy profile
}>()
```

Note: Use optional (`?`) so existing usages (debate thread with v-bind spread) work without change. The debates API already returns `deputyId` in intervention objects, so v-bind spread will auto-pass it.

2. **Replace static name span with conditional NuxtLink:**

Replace:
```html
<span class="font-semibold text-sm text-ink">{{ displayName }}</span>
```

With:
```html
<NuxtLink
  v-if="deputyId"
  :to="`/deputies/${deputyId}`"
  class="font-semibold text-sm text-ink hover:text-bronze transition-colors duration-200"
>
  {{ displayName }}
</NuxtLink>
<span v-else class="font-semibold text-sm text-ink">{{ displayName }}</span>
```

3. **Also make the avatar clickable when deputyId exists:**

Wrap the avatar (both img and initials div) in a `NuxtLink` when `deputyId` is present, or use `component :is="deputyId ? resolveComponent('NuxtLink') : 'div'"` pattern. Simplest: wrap in NuxtLink with `v-if/v-else`:

```html
<component
  :is="deputyId ? 'NuxtLink' : 'div'"
  :to="deputyId ? `/deputies/${deputyId}` : undefined"
  class="flex-shrink-0"
>
  <!-- existing img / initials div -->
</component>
```

This makes both avatar and name clickable when deputyId is present, providing good UX for navigating to deputy profiles from debate threads.

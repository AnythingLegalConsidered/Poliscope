<task type="auto">
  <name>Task 2: Create /search page with URL-synced state and infinite scroll</name>
  <files>app/pages/search.vue</files>
  <action>
Create `app/pages/search.vue` — the main search results page. Follow the exact patterns from 06-RESEARCH.md and the existing deputies/index.vue page:

**State initialization from URL:**
- Read `route.query.q`, `route.query.tag`, `route.query.deputyId` on mount
- `inputValue` ref for raw input (bound to search input via v-model)
- `q` ref for debounced value (URL-synced, triggers API calls)
- `activeTag` ref for tag filter
- `deputyId` ref (parsed as Number or null)

**Debounce:**
- `watchDebounced(inputValue, (val) => { q.value = val }, { debounce: 300 })` from @vueuse/core

**URL sync (one direction: local ref -> URL):**
- `watch([q, activeTag, deputyId], ...)` resets `allResults = []`, `page = 1`, and calls `router.replace()` with non-empty params as query
- Do NOT watch route.query back (avoid double-trigger loop per research pitfall 6)

**Fetch with guard:**
- `useFetch('/api/search', { query: computed(...), immediate: false, watch: false })`
- Manual trigger: `watch([shouldFetch, page], ...)` where `shouldFetch = computed(() => q.value.trim().length > 0)`
- When `shouldFetch` becomes false (empty query), clear results

**Result accumulation:**
- `watch(data, ...)` — if page === 1, replace allResults; else push new results
- `hasMore` computed from pagination.totalPages

**Infinite scroll:**
- `useIntersectionObserver` on sentinel ref (same pattern as deputies page)
- rootMargin: '200px'

**Empty state:**
- When q is empty: show centered placeholder with search icon + "Recherchez une citation, un sujet, un mot-cle..." text
- When q is non-empty but no results: show "Aucun resultat pour [query]"

**Results display:**
- Total count display: "{total} resultats pour '{q}'"
- Active tag filter pill with X button to clear
- v-for on allResults rendering SearchResultCard
- Pass @filter-tag handler that sets activeTag

**Page head:**
- useHead with dynamic title: `Recherche : {q} - Poliscope` or `Recherche - Poliscope` if no q

**Layout:**
- Large search input at top (full width, prominent, larger than header bar)
- Results count + active filters below
- Results grid (single column, max-w-3xl centered — similar to debate thread)
- Sentinel div at bottom for infinite scroll
- LoadingSpinner during fetch

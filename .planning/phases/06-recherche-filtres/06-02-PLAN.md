<task type="auto">
  <name>Task 1: Add search bar to header layout</name>

  <action>
Modify `app/layouts/default.vue` to add a compact search input in the header, between the logo and the nav links (or in the nav area).

**Implementation:**
- Add a `headerSearch` ref (string, empty default)
- Add a form with `@submit.prevent` that calls `navigateTo({ path: '/search', query: { q: headerSearch.value } })` — only if headerSearch is non-empty
- After navigation, clear headerSearch
- Input styling: bg-parchment, border border-stone-border, rounded-lg, px-3 py-1.5, text-sm, placeholder "Rechercher...", focus:border-bronze/40 transition
- Width: w-48 on desktop, hidden on very small screens (hidden sm:block) — or use a search icon button on mobile that expands
- Add a "Recherche" nav link alongside Debats and Deputes that links to /search

**Keep it simple:** Just an input + form submit. No autocomplete, no dropdown. The real search happens on /search.

**Design consistency:** Match the Marbre & Bronze system — parchment background input, stone border, bronze focus ring, Inter font.
  </action>

3. Start dev server, visit / — header should show search input
4. Type "education" and press Enter — should navigate to /search?q=education

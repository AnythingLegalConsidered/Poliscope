  <files>
    packages/ingestion/scripts/ingest_scrutins_an.py

  </files>
  <action>
  1. **Add constant to config.py**:
     ```python
     AN_SCRUTINS_ZIP: str = "https://data.assemblee-nationale.fr/static/openData/repository/17/loi/scrutins/Scrutins.json.zip"
     ```

  2. **Create `ingest_scrutins_an.py`** with these components:

  **Constants:**
  ```python
  SCRUTIN_COLUMNS = [
      "official_id", "title", "date", "chamber", "session_id",
      "legislature_id", "scrutin_type", "result",
      "votes_for", "votes_against", "votes_abstain", "source_url",
  ]
  VOTE_COLUMNS = ["scrutin_id", "actor_id", "position", "delegation_actor_id"]
  ```

  **`load_actor_cache_an(conn)`**: Query `cross_references` WHERE `source_type = 'PA'`. Return `dict[str, int]` mapping `source_id` (e.g., `"PA841657"`) to `actor_id` (DB int id). This is the reliable PA-based matching — no name fallback needed.

  **`map_scrutin_type(code: str)`**: Map AN `codeTypeVote` to schema values:
  - `"SPS"` → `"solemn"` (scrutin public solennel)
  - `"SPO"` → `"ordinary"` (scrutin public ordinaire)
  - Everything else → `"other"`

  **`map_result(code: str)`**: Map AN `sort.code` to schema values:
  - Code contains `"adopté"` (case-insensitive) → `"adopted"`
  - Code contains `"rejeté"` (case-insensitive) → `"rejected"`
  - Everything else → the raw code as-is

  **`extract_votes(scrutin: dict, actor_cache: dict)`**: Navigate `ventilationVotes.organe.groupes.groupe`. CRITICAL: use `listify()` on `groupe` (can be dict when single group). For each group, navigate `vote.decompteNominatif`. Iterate sections: `pours` → `"for"`, `contres` → `"against"`, `abstentions` → `"abstain"`, `nonVotants` → `"absent"`. For each section, use `.get(section_key, {})` (may be missing), then `.get('votant', [])` and `listify()` (single votant = dict). For each votant: resolve `acteurRef` via `actor_cache`. If not found, increment unmatched counter and skip. If found, yield `{"actor_id": ..., "position": ..., "delegation_actor_id": ...}`. For `delegation_actor_id`: check `parDelegation == "true"` (string comparison, not bool); if true, look for `causePositionVote` or just set `delegation_actor_id = None` for now (delegation tracking deferred).

  **`build_scrutin_record(scrutin: dict)`**: Extract fields from the JSON `scrutin` object:
  - `official_id` = `scrutin["uid"]`
  - `title` = `scrutin["titre"]`
  - `date` = parse `scrutin["dateScrutin"]` as date
  - `chamber` = `"AN"`
  - `session_id` = `None` (matching scrutin to debate session is not trivial and not required for Phase 12 — would need seanceRef lookup)
  - `legislature_id` = `None` (no legislatures populated yet)
  - `scrutin_type` = `map_scrutin_type(scrutin["typeVote"]["codeTypeVote"])`
  - `result` = `map_result(scrutin["sort"]["code"])`
  - `votes_for` = `int(scrutin["syntheseVote"]["pour"]["nbrVoix"])`
  - `votes_against` = `int(scrutin["syntheseVote"]["contre"]["nbrVoix"])`
  - `votes_abstain` = `int(scrutin["syntheseVote"]["abstentions"]["nbrVoix"])`
  - `source_url` = `f"https://www.assemblee-nationale.fr/dyn/17/scrutins/{scrutin['uid']}"`

  **`main()`**:
  1. Download ZIP using `download_zip_json_files(AN_SCRUTINS_ZIP)` from utils.py (19 MB — fits in memory, same pattern as AN actors ZIP).
  2. Load actor cache via `load_actor_cache_an(conn)`.
  3. Iterate JSON files. Each file has root key `"scrutin"`. Extract `data["scrutin"]`.
  4. For each scrutin:
     a. `record = build_scrutin_record(scrutin)`
     b. Upsert into `scrutins` using `upsert_query("scrutins", SCRUTIN_COLUMNS, "official_id") + " RETURNING id"`. Get `scrutin_id`.
     c. `DELETE FROM votes WHERE scrutin_id = %s` (idempotent — clear old votes before reinserting).
     d. `votes = extract_votes(scrutin, actor_cache)` — collect all vote dicts.
     e. Bulk insert votes: for each vote, add `scrutin_id` key, then `INSERT INTO votes (scrutin_id, actor_id, position, delegation_actor_id) VALUES (%(scrutin_id)s, %(actor_id)s, %(position)s, %(delegation_actor_id)s)`.
     f. `conn.commit()` after each scrutin (not per-vote — one commit per scrutin for performance).
  5. Log summary: total scrutins processed, total votes inserted, unmatched acteurRef count.
  6. Add `--dry-run` flag support (parse but don't commit).

  **Error handling:** Use `tqdm` progress bar over scrutin files. Wrap each scrutin processing in try/except — log error and continue to next (don't crash entire pipeline on one malformed scrutin).

  <action>
Create `server/api/search.get.ts`:

**Query params:**
- `q` (required) — search query string. If missing or empty, return 400 error.
- `deputyId` (optional) — filter by deputy ID (integer)
- `debateId` (optional) — filter by debate ID (integer)
- `tag` (optional) — filter by tag slug
- `page`, `limit` — via `getPaginationParams(event)`

**Query construction using Drizzle `sql` template:**

1. Build the tsquery: `websearch_to_tsquery('french', ${q})` — this safely handles user input (no need to escape, unlike `to_tsquery`).

2. Base SELECT:
   - `interventions.id`, `interventions.speakerName`, `interventions.speakerRole`, `interventions.orderInDebate`
   - `ts_rank(to_tsvector('french', interventions.content), tsquery)` as `rank`
   - `ts_headline('french', interventions.content, tsquery, 'StartSel=<mark>, StopSel=</mark>, MaxWords=35, MinWords=15, MaxFragments=2, FragmentDelimiter= ... ')` as `highlight`
   - `debates.id` as `debateId`, `debates.title` as `debateTitle`, `debates.date` as `debateDate`
   - `deputies.id` as `deputyId`, `deputies.fullName` as `deputyName`, `deputies.group` as `deputyGroup`, `deputies.photoUrl` as `deputyPhoto`
   - `count(*) over()` as `total_count`

3. FROM `interventions`
   - LEFT JOIN `debates` ON `interventions.debateId = debates.id`
   - LEFT JOIN `deputies` ON `interventions.deputyId = deputies.id`

4. WHERE conditions (always include FTS match):
   - `to_tsvector('french', interventions.content) @@ tsquery` (uses the GIN index)
   - If `deputyId`: `AND interventions.deputy_id = ${deputyId}`
   - If `debateId`: `AND interventions.debate_id = ${debateId}`
   - If `tag`: `AND EXISTS (SELECT 1 FROM intervention_tags it JOIN tags t ON it.tag_id = t.id WHERE it.intervention_id = interventions.id AND t.slug = ${tag})`

5. ORDER BY `rank` DESC, `interventions.id` DESC

6. LIMIT/OFFSET from pagination params

Since this query is complex with raw SQL, use `db.execute(sql\`...\`)` rather than Drizzle's query builder. The `sql` template handles parameterization safely.

Cast `total_count` to Number. Return `paginatedResponse(results, total, page, limit)`.

Wrap in try/catch. On error, throw 500.

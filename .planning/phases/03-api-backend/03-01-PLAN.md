  <files>server/utils/pagination.ts, server/api/debates/index.get.ts</files>
  <action>
Create `server/utils/pagination.ts` with two exported functions:

1. `getPaginationParams(event: H3Event)` — extracts `page` (default 1, min 1) and `limit` (default 20, min 1, max 100) from query params using `getQuery(event)`. Returns `{ page, limit, offset }` where offset = (page - 1) * limit.

2. `paginatedResponse<T>(data: T[], total: number, page: number, limit: number)` — returns `{ data, pagination: { page, limit, total, totalPages: Math.ceil(total / limit) } }`.

Then create `server/api/debates/index.get.ts`:
- Use `defineEventHandler` (auto-imported by Nuxt/Nitro)
- Call `getPaginationParams(event)` for pagination
- Query: select all columns from `debates` table, ordered by `date` DESC
- Use `count(*) over()` window function via `sql` template to get total count in same query: `sql<number>\`count(*) over()\`.as('total_count')`
- Cast total_count to Number (postgres returns string for bigint)
- Return `paginatedResponse(debates, total, page, limit)`
- Wrap in try/catch, throw `createError({ statusCode: 500 })` on failure

Note: `db` is auto-imported from `server/utils/db.ts` by Nuxt. `getQuery`, `createError`, `defineEventHandler` are auto-imported from H3.

<task type="auto">
  <name>Task 2: Debate detail endpoint with interventions</name>
  <files>server/api/debates/[id].get.ts</files>
  <action>
Create `server/api/debates/[id].get.ts`:
- Use `getRouterParam(event, 'id')` to get debate ID
- Parse ID to integer, throw `createError({ statusCode: 400, message: 'Invalid debate ID' })` if NaN
- Query debate by ID from `debates` table using `eq(debates.id, id)`
- If not found, throw `createError({ statusCode: 404, message: 'Debate not found' })`
- Query interventions for this debate from `interventions` table where `eq(interventions.debateId, id)`, ordered by `orderInDebate` ASC
- For each intervention, left join `deputies` table to get `fullName`, `group`, `photoUrl` for the speaker (using `deputyId`)
- Also fetch tags for each intervention: query `interventionTags` joined with `tags` where interventionId matches, then group into a map. Attach tags array to each intervention to avoid N+1.
- Return `{ debate, interventions }` where interventions include deputy info and tags

Use Drizzle's `leftJoin` for the deputy join. For tags, do a single batch query for all intervention IDs in the debate, then map them client-side.
  </action>

- `curl http://localhost:3000/api/debates/999` returns 404
- `curl http://localhost:3000/api/debates/abc` returns 400
- Interventions are ordered by orderInDebate ascending
  </verify>

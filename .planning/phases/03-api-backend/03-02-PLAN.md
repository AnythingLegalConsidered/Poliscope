<task type="auto">
  <name>Task 1: Deputies list endpoint with filters</name>
  <files>server/api/deputies/index.get.ts</files>
  <action>
Create `server/api/deputies/index.get.ts`:
- Use `getPaginationParams(event)` (auto-imported from server/utils/) for pagination
- Extract optional query params via `getQuery(event)`: `group` (political group filter), `search` (name search)
- Build WHERE conditions array:
  - If `group` provided: `eq(deputies.group, group)`
  - If `search` provided: `ilike(deputies.fullName, '%${search}%')` — use `ilike` from drizzle-orm for case-insensitive name search. Sanitize by stripping SQL wildcards from the search input before wrapping with %.
- Use `and(...conditions)` if multiple conditions, or no WHERE if no filters
- Query with `count(*) over()` window function for total count (same pattern as debates list)
- Order by `lastName` ASC, `firstName` ASC
- Return `paginatedResponse(deputies, total, page, limit)`
- Wrap in try/catch with 500 error
  </action>
  <verify>
- `curl http://localhost:3000/api/deputies` returns paginated list of deputies
- `curl "http://localhost:3000/api/deputies?group=Renaissance"` filters by political group
- `curl "http://localhost:3000/api/deputies?search=dupont"` searches by name (case insensitive)
- `curl "http://localhost:3000/api/deputies?page=2&limit=10"` paginates correctly
  </verify>
  <done>GET /api/deputies returns paginated deputies with optional group filter and name search</done>

<task type="auto">
  <name>Task 2: Deputy detail endpoint with interventions and tags</name>
  <files>server/api/deputies/[id].get.ts</files>
  <action>
Create `server/api/deputies/[id].get.ts`:
- Parse ID from `getRouterParam(event, 'id')`, validate as integer (400 if invalid)
- Query deputy by ID, throw 404 if not found
- Extract optional pagination params for interventions via `getPaginationParams(event)`
- Query interventions where `deputyId = id`, ordered by `createdAt` DESC, with pagination
- For each intervention, include the debate title and date via left join on `debates` table
- Batch-fetch tags for the returned interventions (same pattern as debates detail)
- Compute tag distribution: query `interventionTags` joined with `tags` where the intervention belongs to this deputy, group by tag name, count occurrences. Return as `tagStats: { name: string, slug: string, count: number }[]`
- Return `{ deputy, interventions: paginatedResponse(interventions, total, page, limit), tagStats }`
  </action>

- `curl http://localhost:3000/api/deputies/1` returns deputy profile with paginated interventions and tagStats
- `curl http://localhost:3000/api/deputies/999` returns 404
- `curl "http://localhost:3000/api/deputies/1?page=2&limit=5"` paginates interventions
- tagStats shows tag names with counts
  </verify>
  <done>GET /api/deputies/:id returns deputy profile, paginated interventions with debate context, and tag distribution stats</done>

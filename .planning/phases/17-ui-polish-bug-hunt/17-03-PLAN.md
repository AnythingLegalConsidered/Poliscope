    Pattern to reproduce:
    1. **SSR page 1 via `useFetch`**: keep the existing `const { data } = await useFetch(\`/api/debates/${id}\`, { query: { page: 1, limit: 20 } })`. This gives SSR-rendered page 1 and prevents hydration mismatch.
    2. **Accumulator ref**: `const interventions = ref<Intervention[]>(data.value?.interventions ?? [])`. Seed from the SSR payload on first render.
    3. **Pagination state**: `const page = ref(1)`, `const hasMore = ref(data.value?.pagination.hasMore ?? false)`, `const loading = ref(false)`, `const total = ref(data.value?.pagination.total ?? 0)`.
    4. **loadMore function**:
       ```ts
       async function loadMore() {
         if (loading.value || !hasMore.value) return
         loading.value = true
         try {
           const next = page.value + 1
           const res = await $fetch(`/api/debates/${id}`, { query: { page: next, limit: 20 } })
           interventions.value.push(...res.interventions)
           page.value = next
           hasMore.value = res.pagination.hasMore
           total.value = res.pagination.total
         } finally {
           loading.value = false
         }
       }
       ```
    5. **Load-more button UI** (prefer button over IntersectionObserver for Playwright stability — 17-RESEARCH.md flags IO flakiness):
       ```html
       <div v-if="hasMore" class="flex justify-center py-6">
         <button
           type="button"
           @click="loadMore"
           :disabled="loading"
           class="px-6 py-2 border border-bronze text-bronze hover:bg-bronze hover:text-marble transition font-cinzel text-sm"
           data-testid="debate-load-more"
         >
           {{ loading ? 'Chargement...' : 'Charger plus' }}
         </button>
       </div>
       ```
       (Use exact existing button class pattern from deputies/[id].vue for consistency — copy-paste rather than invent.)
    6. **Header intervention count**: Find where the current page displays the intervention count in the debate header (something like `{{ interventions.length }} interventions`). Swap to `{{ total }} interventions` so the user sees the TRUE total even when only a subset is rendered. Pluralize if the existing code pluralizes. ALSO add `data-testid="debate-intervention-count"` to the element wrapping that count (natural because 17-03 owns this header edit — 17-04's debate-pagination.spec.ts will read it).

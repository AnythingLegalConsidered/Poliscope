  <action>
  Create `packages/ingestion/scripts/ingest_debates_senat.py` following the same structural pattern as `ingest_debates.py` (post-refactoring). Key differences:

  **Constants:**
  - `DILA_SENAT_ZIP = "https://data.senat.fr/data/debats/cri.zip"`
  - `XVIIE_START = datetime(2022, 6, 22)` — filter sessions from this date
  - `DEBATE_COLUMNS` — same as AN but always `chamber='Senat'`
  - `INTERVENTION_COLUMNS` — same as AN but always `chamber='Senat'`

  **Download (CRITICAL — memory safe):**
  - `download_cri_zip_to_temp()`: Use `httpx.stream('GET', url, timeout=600, follow_redirects=True)` writing chunks to `tempfile.NamedTemporaryFile(suffix='.zip', delete=False)`. Return the temp file path. DO NOT use `httpx.get().content` — 510 MB would OOM on 4GB LXC.
  - Accept `--senat-zip-path` CLI arg to skip download and use a local file.

  **Iteration:**
  - `iter_xviie_sessions(zip_path, start_date)`: Open with `zipfile.ZipFile`, iterate namelist, parse date from filename pattern `SEN_YYYYMMDD_NNN.xml` (or similar — handle both .xml and .taz entries), filter by `start_date`, yield `(filename, xml_bytes)`.
  - If files inside the ZIP are .taz instead of .xml, extract the inner XML from the .taz using the same nested tar pattern as the AN pipeline.

  **XML Parsing — `parse_senat_cri_xml(xml_bytes)`:**
  - Root element: `PublicationDSenat`
  - Metadata path: `root/Metadonnees` — extract `dateSeance`, `numParution`, `numSeance`
  - **Date parsing (CRITICAL):** `dateSeance` has timezone offset like `"2024-01-15+01:00"`. Strip timezone with `re.sub(r'[+-]\d{2}:\d{2}$', '', date_str)` before `datetime.strptime(date_clean, "%Y-%m-%d")`.
  - Session title: from `PresidentSeance` element text in `ContenuDSenat/CompteRendu/Contenu`, or fallback `"Seance du {date}"`
  - official_id format: `"SEN-{date_clean}-{numParution:0>3}"` (e.g. `"SEN-2024-01-15-001"`)
  - Interventions: iterate all `Para` elements with `Orateur/Nom` child
  - **Speaker name (CRITICAL):** Strip trailing punctuation `".,;: "` from `<Nom>` text — XML has `"M. Francois Marc."` with trailing period
  - Speaker role: from `Orateur/Qualite` child text (not `QualiteMouvement` as in AN)
  - Content: `etree.tostring(para, method='text', encoding='unicode')` minus speaker name prefix. Reuse the `_extract_speech_content()` and `_clean_unicode()` helpers from `ingest_debates.py` by importing them, OR duplicate them.

  **Senator matching — `load_senator_cache(conn)`:**
  - Query: `SELECT id, official_id, full_name FROM actors WHERE chamber = 'Senat'`
  - Build `by_name` dict only (no `by_official_id` — Senat XML has no href/ID on Orateur)
  - Reuse `normalize_name()` from `ingest_debates.py` (import it)

  **`match_senator(speaker_name, by_name)`:**
  - Name-only matching: `normalize_name(clean_name)` lookup in by_name
  - Clean prefixes: strip `"M.", "Mme", "Mme."` etc.
  - Log unmatched names to a file `senat_unmatched_speakers.log` for post-run analysis

  **DB operations:**
  - Reuse `upsert_query()` from `db.py` for debates
  - Reuse delete-then-insert pattern from AN pipeline for interventions (idempotent)
  - Wrap each session in a transaction (commit per session)

  **CLI args:**
  - `--limit N` — max sessions to process
  - `--start-date YYYY-MM-DD` — override default XVIIe start
  - `--dry-run` — parse without DB writes
  - `--senat-zip-path PATH` — use local file instead of downloading
  - `--log-unmatched` — write unmatched speaker names to file

  **Stats tracking:** Same pattern as AN — debates_processed, interventions_inserted, actor_matches, actor_unmatched, errors, skipped_date

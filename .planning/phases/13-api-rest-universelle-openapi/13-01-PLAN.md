  <files>

  <action>
    Create `packages/web/server/api/votes/` directory with two files.

    **index.get.ts — GET /api/votes (list scrutins):**
    Follow the exact same pattern as `debates/index.get.ts`:
    - Import `sql, desc, eq, and` from drizzle-orm, `scrutins` from shared/schema
    - Use `getPaginationParams(event)` for pagination (auto-imported)
    - Use `db` (auto-imported from server/utils)
    - Accept query params: `chambre` (AN|Senat), `dateFrom` (ISO date), `dateTo` (ISO date), `result` (adopted|rejected)
    - Build conditions array: chamber filter via `eq(scrutins.chamber, chamber)`, date range via `gte/lte(scrutins.date, ...)`, result via `eq(scrutins.result, result)`
    - Select fields: id, officialId, title, date, chamber, scrutinType, result, votesFor, votesAgainst, votesAbstain, sourceUrl, totalCount (window function)
    - Order by `desc(scrutins.date)`
    - Return `paginatedResponse(data, total, page, limit)`
    - Wrap in try/catch, throw 500 on error

    **[id].get.ts — GET /api/votes/:id (scrutin detail):**
    Follow the pattern of `debates/[id].get.ts`:
    - Parse id from `getRouterParam(event, 'id')`, validate as number, throw 400 if invalid
    - Fetch scrutin row from `scrutins` table where `eq(scrutins.id, id)`, throw 404 if not found
    - Fetch per-actor votes with pagination (MANDATORY — 1.3M votes total):
      - Use `getPaginationParams(event)` for vote pagination
      - Select: votes.id, votes.actorId, votes.position, actors.fullName (as actorFullName), actors.group (as actorGroup), actors.photoUrl (as actorPhotoUrl), totalCount window function
      - LEFT JOIN actors on `eq(votes.actorId, actors.id)`
      - WHERE `eq(votes.scrutinId, id)`
      - Accept optional `position` query param to filter by position (for|against|abstain|absent)
      - Order by actors.lastName ASC (so votes are alphabetical by actor)
    - Return `{ scrutin: scrutinData, votes: paginatedResponse(voteData, total, page, limit) }`
    - Import `actors` from shared/schema for the join
  </action>

    - `curl http://localhost:3000/api/votes?chambre=Senat` returns only Senat scrutins

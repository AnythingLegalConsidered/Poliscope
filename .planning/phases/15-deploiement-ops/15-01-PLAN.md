Create a `deploy/` directory at repo root with 4 files:

**deploy/provision.sh** — One-time LXC setup script (run as root on LXC):
1. Install Node.js 22 LTS via NodeSource (`curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs`)
2. Install PM2 globally (`npm install -g pm2`)
3. Install nginx (`apt-get install -y nginx`)
4. Create directory structure: `/opt/poliscope/{.output,repo,backups,logs,scripts}`
5. Open UFW port 80/tcp (`ufw allow 80/tcp`)
6. Remove default nginx site (`rm -f /etc/nginx/sites-enabled/default`)
7. Copy nginx config: `cp /opt/poliscope/repo/deploy/nginx/poliscope.conf /etc/nginx/sites-available/poliscope && ln -sf /etc/nginx/sites-available/poliscope /etc/nginx/sites-enabled/`
8. `nginx -t && systemctl enable --now nginx`
9. Setup PM2 startup: `pm2 startup systemd -u root --hp /root` then `pm2 save`
10. Print summary of what was done

Add `set -euo pipefail` and status echo before each step. Make idempotent (use `mkdir -p`, `apt-get install -y`, etc.).

**deploy/deploy.sh** — Repeatable deploy script (run from local dev machine):
1. Accept optional `--skip-build` flag
2. If not skipped: `pnpm --filter web build` from repo root
3. Create production `.env` at `deploy/.env.production` if it doesn't exist (template with `NUXT_DATABASE_URL=postgresql://poliscope:PASSWORD@localhost:5432/poliscope`)
4. `rsync -avz --delete packages/web/.output/ root@192.168.2.200:/opt/poliscope/.output/`
5. `rsync -avz deploy/.env.production root@192.168.2.200:/opt/poliscope/.env`
6. `rsync -avz deploy/ecosystem.config.cjs root@192.168.2.200:/opt/poliscope/ecosystem.config.cjs`
7. SSH and restart: `ssh root@192.168.2.200 "cd /opt/poliscope && pm2 startOrRestart ecosystem.config.cjs --env production && pm2 save"`
8. Verify: `curl -sf http://192.168.2.200/api/health` and print result

Use `set -euo pipefail`. LXC_HOST variable at top for easy change. Add color output for steps.

**deploy/ecosystem.config.cjs** — PM2 config:
```js
module.exports = {
  apps: [{
    name: 'poliscope',
    script: '/opt/poliscope/.output/server/index.mjs',
    cwd: '/opt/poliscope',
    instances: 1,
    exec_mode: 'fork',
    env: {
      NODE_ENV: 'production',
      NITRO_PORT: '3000',
    },
    env_file: '/opt/poliscope/.env',
    max_memory_restart: '512M',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
  }],
}
```

**deploy/nginx/poliscope.conf** — nginx reverse proxy:
```nginx
server {
    listen 80;
    server_name poliscope.fr _;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Also create `deploy/.env.production.example` with placeholder values (DATABASE_URL template). Add `deploy/.env.production` to `.gitignore`.

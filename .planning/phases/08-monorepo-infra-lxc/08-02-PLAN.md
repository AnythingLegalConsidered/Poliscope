<task type="auto">
  <name>Task 1: Create Ansible playbook, inventory, and variables for LXC + PG17</name>
  <files>
    ansible/requirements.yml
    ansible/inventory.ini
    ansible/group_vars/all.yml
    ansible/playbook.yml
  </files>
  <action>
    1. Create `ansible/requirements.yml` — Ansible Galaxy collection dependencies:
       ```yaml
       ---
       collections:
         - name: community.proxmox
         - name: community.postgresql
         - name: community.general
         - name: ansible.posix
       ```

    2. Create `ansible/inventory.ini` with two host groups:
       ```ini
       [pve]
       pve02 ansible_host=<PVE02_IP> ansible_user=root

       [lxc]
       poliscope-db ansible_host=<LXC_IP> ansible_user=root
       ```
       Use placeholder IPs — user fills in before running.

    3. Create `ansible/group_vars/all.yml` with all configurable variables:
       ```yaml
       ---
       # LXC configuration
       lxc_vmid: 200
       lxc_hostname: poliscope-db
       lxc_ip: "<LXC_IP>"
       lxc_gw: "<GATEWAY_IP>"
       lxc_cidr: 24

       # PVE02 API authentication
       pve_node: pve02
       pve_api_host: "<PVE02_IP>"
       pve_api_user: "root@pam"
       # For API token auth (more secure), replace above with:
       # pve_api_user: "ansible@pve"
       # pve_api_token_id: "automation"
       # pve_api_token_secret: "<TOKEN_SECRET>"

       # LXC resources
       lxc_cores: 4
       lxc_memory: 4096
       lxc_disk: "local-lvm:100"
       lxc_template: "local:vztmpl/debian-12-standard_12.7-1_amd64.tar.zst"
       lxc_bridge: vmbr0

       # PostgreSQL
       pg_db: poliscope
       pg_user: poliscope
       pg_password: "<CHANGE_ME>"
       lan_subnet: "<LAN_SUBNET>/24"

       # SSH
       ssh_pubkey_path: "~/.ssh/id_ed25519.pub"
       ```
       All `<PLACEHOLDER>` values must be filled by user before running.

    4. Create `ansible/playbook.yml` — two-play idempotent playbook:

       **Play 1 — Create LXC on PVE02 host:**
       - Download Debian 12 template if not present (pveam download, with creates: guard)
       - Create LXC container using `community.proxmox.proxmox` module with specs from variables
       - Start the LXC container
       - Wait for SSH to become available on LXC

       **Play 2 — Configure PostgreSQL 17 on LXC:**
       - Install prerequisites: curl, ca-certificates, gnupg, python3-psycopg2
       - Add PGDG GPG key (apt_key module, keyring path)
       - Add PGDG apt repository for bookworm-pgdg
       - Install postgresql-17 and postgresql-client-17
       - Ensure PostgreSQL service is started and enabled
       - Set `listen_addresses = '*'` in postgresql.conf (notify restart handler)
       - Add pg_hba.conf entry for LAN subnet using `community.postgresql.postgresql_pg_hba` (scram-sha-256)
       - Create poliscope database using `community.postgresql.postgresql_db`
       - Create poliscope user with password using `community.postgresql.postgresql_user` with ALL privileges on poliscope db
       - Configure UFW firewall: allow SSH (22), PG from LAN (5432), Nuxt from LAN (3000), default deny
       - Enable UFW
       - Handler: restart postgresql service

       Follow the exact Ansible module patterns from the research (08-RESEARCH.md Pattern 7). Use `become: true` for Play 2, `become_user: postgres` for DB/user creation tasks.

       Important implementation details:
       - The template download task should use a shell task with `pveam download local debian-12-standard_12.7-1_amd64.tar.zst` and `creates: /var/lib/vz/template/cache/debian-12-standard_12.7-1_amd64.tar.zst` for idempotency
       - Use `api_password` auth by default (simpler for first run), with comments showing API token alternative
       - Add `wait_for` task between Play 1 and Play 2 to ensure SSH is up on the LXC before configuring it
       - All tasks must be idempotent (playbook reexecutable without side effects)
  </action>

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Run Ansible playbook on PVE02</name>
  <what-to-do>
    The Ansible playbook is ready in `ansible/`. You need to:

    1. **Fill in variables** — edit `ansible/group_vars/all.yml`:
       - `lxc_ip`: IP address for the LXC on your LAN (e.g., 192.168.1.200)
       - `lxc_gw`: Your LAN gateway IP
       - `pg_password`: Choose a password for the poliscope PG user
       - `lan_subnet`: Your LAN subnet (e.g., 192.168.1.0)
       - `pve_api_host`: PVE02 IP address

    2. **Fill in inventory** — edit `ansible/inventory.ini`:
       - Replace `<PVE02_IP>` with PVE02's actual IP
       - Replace `<LXC_IP>` with the chosen LXC IP

    3. **Verify prerequisites on PVE02:**
       - Debian 12 CT template downloaded (PVE UI -> local -> CT Templates)
       - SSH access to PVE02 works from your machine

    4. **Install Ansible collections:**
       ```bash
       cd ansible && ansible-galaxy collection install -r requirements.yml
       ```

    5. **Run the playbook:**
       ```bash
       ansible-playbook -i inventory.ini playbook.yml
       ```

    6. **Verify PostgreSQL access from dev machine:**
       ```bash
       psql -h <LXC_IP> -U poliscope -d poliscope -c "SELECT version();"
       ```
       Should return PostgreSQL 17.x.

    7. **Update `.env`** at repo root with actual values:
       ```
       DATABASE_URL=postgresql://poliscope:<password>@<LXC_IP>:5432/poliscope
       NUXT_DATABASE_URL=postgresql://poliscope:<password>@<LXC_IP>:5432/poliscope
       NUXT_SITE_URL=https://poliscope.fr
       ```
  </what-to-do>
  <resume-signal>Confirm "done" once psql connects successfully and .env is configured, or describe any issues.</resume-signal>
